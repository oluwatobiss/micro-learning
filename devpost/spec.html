MicroLearning Studio — Technical Spec

React Router Framework Mode • TypeScript • CSS Modules • Native CSS Custom Properties. Production-grade architecture with zero UI library bloat.

System Architecture & Route Structure
Technical Blueprint Details

React Router v7 (Framework Mode)

Provides official route conventions, route loaders, nested layouts, and SSR readiness without manual routing plumbing.

TypeScript

Strict compile-time type safety across Lesson, Card, Quiz, and Theme models.

CSS Modules

Component-scoped classes (*.module.css) preventing naming collisions and style leakage.

Native CSS Custom Properties

Zero-runtime token switching for Clean Light, Focused Dark, and Warm Editorial themes.

RootLayout & ThemeToggle prd.md > Screens and Layout

Maintains persistent header, theme state, and child route outlet.

ReaderLandingRoute prd.md > 1. Reader Experience

Showcases featured lessons, reading time estimates, and quick launch.

ReaderPlayer & CheckpointCard prd.md > 5. Checkpoint Mechanics

Card-by-card navigation with visible controls, interactive quiz states, and grounded explanations.

SourceInput & ProgressOverlay prd.md > 2. Source Input & 3. Pipeline

Validation, authorization acknowledgement, and 5-stage live extraction tracker.

DeckEditor prd.md > 4. Studio Editor & Polish

Granular card control: editing text, reordering, locking cards against regeneration, and publishing. 

export type ThemeMode = 'clean-light' | 'focused-dark' | 'warm-editorial';

export type CardType = 'narrative' | 'example' | 'comparison' | 'checkpoint';

export interface QuizOption {
  id: string;
  text: string;
  isCorrect: boolean;
}

export interface QuizCheckpoint {
  question: string;
  options: QuizOption[];
  explanation: string;
  sourceExcerpt?: string;
}

export interface LessonCard {
  id: string;
  type: CardType;
  title: string;
  content: string;
  isLocked?: boolean;
  visualSvg?: string;
  checkpoint?: QuizCheckpoint;
}

export interface Lesson {
  id: string;
  title: string;
  author: string;
  sourceUrl: string;
  sourceSnippet: string;
  estimatedMinutes: number;
  createdAt: string;
  cards: LessonCard[];
}
