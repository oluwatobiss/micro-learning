The Two-Surface Product Architecture
Product Specification & Surfaces

Reader Landing & Interactive Card Deck

The reader experiences a calm, anti-doomscroll environment. No login required.

  • Showcase Discovery: Cards show lesson title, author attribution, estimated time (e.g. 4 min), and source link.
  • Card Progression: Visible Next, Previous, and progress indicators (e.g. Card 2 of 5). No hidden gesture-only navigation.
  • Grounded Checkpoint: Interactive multiple-choice check grounded in source text. Must answer before advancing.
  • Immediate Explanation: Unlocks pedagogical explanation immediately upon answering with visual confirmation.
  • Completion Screen: Key takeaway recap, completion badge, and link to read original full-length publication.

Creator Studio & Adaptive Pipeline

Creators retain complete editorial authority with high-speed editing tools.

  • Input Validation: Title, author, original URL, minimum 200 words, and authorization acknowledgement checkbox.
  • Quick Start: "Load Sample Article" button populates rich educational sample text for instant demoing.
  • Generation Stages: Step-by-step progress tracking: Understanding source → Planning lesson → Creating cards → Creating checks → Ready.
  • Deck Editor: Edit text, reorder cards, change card types (Narrative, Comparison, Checkpoint), lock cards, and duplicate/delete.
  • Regeneration & Publish: Regenerate individual cards without wiping the deck. Click Publish to view directly as a reader.

Three Distinctive Reading Environments

Premium typography and contrast options without unnecessary decorative bloat:

Clean Light

Crisp white/neutral slate, high-contrast dark text, clean modern feel for daytime study.

Focused Dark

Deep navy/charcoal, elevated dark surfaces, glowing cyan accents for immersive evening reading.

Warm Editorial

Soft cream/linen background, sepia ink, warm-stone borders inspired by physical literary essays.

Observable Acceptance Criteria

  • ✓
    Friction-Free Reader Start: Reader landing page displays featured lesson; clicking it opens the player on Card 1 without prompts.
  • ✓
    Adaptive Card Count: Lessons adaptively generate between 4 to 8 cards based on source density, with checkpoints at natural intervals.
  • ✓
    Input Guardrails: "Generate Lesson" button is disabled until valid source length and authorization checkbox are confirmed.
  • ✓
    Studio Editorial Control: Creator can edit card headlines, body text, reorder cards, and lock approved wording.
  • ✓
    Grounded Checkpoint Verification: Quiz reveals instant correct/incorrect visual state and educational explanation before allowing progression.
  • ✓
    Theme Switching: Header theme toggle updates all colors, card surfaces, and text across the entire application instantly.

States and Edge Cases

  • Empty Input State: Clear placeholder hints and "Load Sample Article" quick-action button.
  • Generation Progress State: Visible progress indicator cycling through the 5 extraction stages.
  • Input Error State: Inline warning if pasted text is under 200 words or missing author attribution.
  • Locked Cards: Locked cards show a lock icon and are preserved during any deck regeneration.
  • Local Persistence: Published lessons are stored in local storage so they remain available when browsing lessons.
